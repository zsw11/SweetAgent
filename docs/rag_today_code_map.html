第一层 · 部门 Agent 入口（app/agents/base.py）
类属性：KNOWLEDGE_DEPARTMENT（部门标签，检索时过滤）+ KNOWLEDGE_TOP_K=5

↓ task 原文
第二层 · 核心检索（app/knowledge/retriever.py · KnowledgeRetriever）
① embed_query(query) → mock/真实向量（1536 维）
② _vector_search：余弦 SQL + JOIN documents 过滤（SQL 层压缩 top-k）
③ 判断：top1 ≥ 0.20？→ 用向量结果
top1 < 0.20 → _keyword_search（_extract_keywords 拆词：英文整词 + 中文 2-gram + 虚词过滤；ILIKE OR + 命中数降序）
④ 双通道都不可信 → 返回 []（log knowledge.retrieve.none）
⑤ _stamp_confidence（新增）：每条命中打 confidence = _evidence_confidence(similarity, hit_count, method)
vector：≥0.60 high / 0.30~0.60 medium / <0.30 low；keyword：命中 ≥3 high / 2 medium / 1 low
↓ hits（含 confidence）
第三层 · 组装与提示（app/agents/base.py，本次改动）
_query_knowledge：整体 confidence = hits[0]["confidence"]，空 → "none"；rows 每行带 confidence；observation 加 confidence 字段
_analyze：observations 含 knowledge 且 confidence=none → system prompt 动态追加 「知识库未收录相关内容，必须如实说明，禁止编造或猜测知识库规则内容」
↓ result_json（含 confidence）→ LLM 分析 → Decision 汇总
