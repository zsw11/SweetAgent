企业知识库 RAG 真闭环
文档摄入（构建期）→ 向量检索（推理期）→ 部门 Agent 注入 | 示意结构
① 离线摄入（构建期 · scripts/ingest_knowledge.py）
seed_docs.py 11 篇种子文档
O/F/L/P/company 五域 · sections 结构化（标题+正文）
↓
chunker.py 文档切分
段落优先（空行分隔）· 超长段落 500 字窗口 + 50 字重叠
↓
embedder.py 批量向量化
Key 有效 → 真实模型 text-embedding-3-small（1536 维）
Key 无效/失败 → 自动降级 mock_embedding（同文本=同向量）
↓
ingest.py 写入三表（按 title 幂等：先删后建）
knowledge_documents（1 行）→ knowledge_chunks（33 行）→ knowledge_embeddings（33 行，model/dim 落库可追溯）
② 在线检索（推理期 · 部门 Agent 内）
用户问题（如「库存补货预警规则是什么？」）
LLM plan 阶段自主决定查知识库 → 数据域 knowledge
↓
retriever.search() 混合检索
query 向量化 → PGVector 余弦 top-k(5) + metadata 过滤（department 隔离）
向量最高分 < 0.20？ → 关键词兜底
英文连续词 + 中文 2-gram 提取 · 按命中词数降序（保底不漏检）
↓
命中片段注入（title / content / similarity / method）
observations 结构与 SQL 查询同构 → analyze 阶段无需区分来源
③ 部门接入（四部门共用基类 BaseDepartmentAgent）
类属性 KNOWLEDGE_DEPARTMENT（检索时按部门过滤）
KNOWN_REQS 加 knowledge · PRIORITY_TABLES 加 documents/chunks
特判 _query_one 中 req=="knowledge" → 不生成 SQL，直接走 _query_knowledge()（RAG）
结果归一 返回 columns/rows/row_count/duration_ms/sql 与 SQL 查询一致
职责分离（Product） market=文档清单 · knowledge=内容检索
