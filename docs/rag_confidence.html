改进设计：检索证据置信度分级（而不是"有/没有"二值）
你的质疑 → 承认"没有合适检索"要成为一等公民 | 示意
当前实现的问题：search() 只返回"有结果 / 空列表"二值。空列表时 LLM 会自己写一句「知识库检索结果为空」——但这是 LLM 的自由发挥，系统没有给它一个明确信号："这里没有可信依据，禁止编造"。
高 · 强证据
向量高分（≥0.60）+ 关键词命中 ≥2 词 同时成立
下游：放心引用，可溯源
中 · 弱证据
关键词命中 2~3 词，或向量 0.30~0.60
下游：可参考方向，不引用具体数字
低 · 疑似噪声
只命中 1 词，或向量 0.20~0.30
下游：不引用，明确标注"未验证"
无 · 无合适检索
关键词 0 命中（或命中词全为垃圾 2-gram）
下游：显式回答"知识库未收录"，禁止编造
为什么"关键词命中"仍然提供价值（即便它也会错）：
向量分低 = "我无法判断相不相关"（黑盒估计，方向不明）
关键词命中 = "字面确实包含这些词"（可验证的事实，虽不等于语义相关）
所以兜底的意义不是"更可信"，而是换一个可解释、可验证的证据来源——但它同样要接受置信度分级，命中数太少就该判"无"。
